AGENT ORCHESTRATION

可追踪的测试工作流

四个职责节点、一份持久化状态、可复核的浏览器证据。

01

Test Planner

读取目标页面，结合自然语言生成受 JSON Schema 约束的步骤；无密钥时使用明确标识的演示模板。

02

Browser Agent

使用 Playwright 执行导航、点击、输入与多页面流程。关键步骤经 LangGraph interrupt 等待人工审批。

03

Verifier

显式检查页面文本、元素和 URL，校验 Console 与 Network。只读操作可限次重试，提交不会自动重放。

04

Failure Analyzer

依据实际响应状态、运行异常和 DOM 归类故障。可选 Chrome DevTools MCP 连接同一浏览器补充证据。

检查点与可观测性

LangGraph 状态保存在 SQLite 检查点文件；业务任务、步骤和事件可写入 MySQL。暂停审批能在服务重启后保留；执行中页面无法可靠恢复时，明确标记中断，并要求重新创建任务。

所有任务有本地事件记录与 Playwright trace。配置 Langfuse 后，模型调用和工作流节点以实际 SDK observation 上报。

访问令牌

如果服务配置了 AUTOQA_API_TOKEN，在这里输入。令牌仅保存在当前浏览器会话。

配置示例

AUTOQA_ALLOWED_ORIGINS=https://your-test-site.example
AUTOQA_LLM_BASE_URL=https://your-provider.example/v1
AUTOQA_LLM_MODEL=your-model
AUTOQA_LLM_API_KEY=your-api-key
AUTOQA_DATABASE_URL=mysql+pymysql://user:password@localhost/autoqa

测试目标需加入允许列表。模型密钥在服务端读取，浏览器界面不会接触密钥。完整说明见项目 README。
